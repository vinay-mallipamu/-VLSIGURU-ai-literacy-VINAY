## 1. Most important difference between traditional ML and deep learning
Traditional ML often depends on features selected or designed by people, while deep learning uses multi-layer neural networks that can learn useful representations from data. The best choice still depends on the problem and evidence.

## 2. How data preparation affects learning
A neural network learns from the numerical examples and labels it receives. Incorrect labels, poor image quality, duplicates, class imbalance or unrepresentative data can cause misleading learning and poor predictions on new data.

## 3. What happens inside a network during learning
The network performs a forward pass to make a prediction. A loss function compares the prediction with the target. Backpropagation calculates gradients, and an optimiser updates weights and biases. This process repeats over batches and epochs.
