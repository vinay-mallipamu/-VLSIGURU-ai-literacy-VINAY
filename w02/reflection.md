# Week 02 Reflection

1. **Which ML concept became clearest to me this week, and what helped?**  
   The difference between classification and regression became clearer. Classification predicts a category such as Pass/Fail, while regression predicts a number such as delay in nanoseconds. The Physical Design examples helped me connect the definitions to engineering work.

2. **Which two concepts are easy to confuse? How do I distinguish them now?**  
   Learning paradigms and task types are easy to confuse. A learning paradigm describes how a model learns, while a task type describes the output it needs to produce. For example, supervised learning can be used for a classification task.

3. **What is one claim I checked against a reliable source, and what did the source establish?**  
   Google's introductory ML material explains that supervised learning uses labelled examples and that regression predicts numerical values while classification predicts categories.

4. **Which stage of the ML lifecycle is easiest to underestimate, and why?**  
   Data preparation is easy to underestimate. Incorrect labels, missing values or data that does not represent real designs can make the model unreliable even if the algorithm is suitable.

5. **What is one question I want answered before moving into deep learning?**  
   I want to understand how to choose useful features and evaluate a model on unseen data before learning how neural networks train.
