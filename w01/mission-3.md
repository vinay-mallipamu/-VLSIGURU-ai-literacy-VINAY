3)Classify 5 examples as rule-based, ML, or generative AI


| # | System                   | Classification                    | Why                                                                      |
| - | ------------------------ | --------------------------------- | ------------------------------------------------------------------------ |
| 1 | Calculator               | Rule-based / traditional software | Follows fixed math rules and gives the same output for the same input.   |
| 2 | Temperature warning rule | Rule-based / traditional software | Uses a fixed threshold, such as “if temperature > 40°C, show a warning.” |
| 3 | Spam filter              | ML-based AI                       | Learns from labelled emails to identify patterns that indicate spam.     |
| 4 | Document summariser      | Generative AI                     | Generates new text that summarises the document.                         |
| 5 | Traffic ETA prediction   | ML-based AI                       | Predicts travel time using patterns in historical and live traffic data. |


1)Easy: calculator. Every step is a rule a programmer wrote, and nothing is learned from data. There is no training and no model, so it was clearly traditional software.

2)Difficult: spam filter. Some filters just block certain words or senders, which is rule-based. Others learn from examples, which is ML. Most real filters use both, so “mainly” was hard to decide. I chose ML because spammers keep changing their wording, and hand-written rules can’t keep up.

3)My own example: phone keyboard suggestions. A basic dictionary-based autocorrect is rule-based. But suggestions that adapt to my own slang and names come from a model that learned my typing patterns, so I classed it as ML-based AI.
